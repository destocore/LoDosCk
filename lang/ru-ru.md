>[!Important]
>**LoDosCk** — это ультра-легковесный асинхронный движок сетевой безопасности промышленного уровня, разработанный специально для 
>прокси-инфраструктуры **Velocity**. 
>
>Плагин спроектирован в рамках жестких High-Load ограничений. На выделенном контуре всего в **1 ГБ RAM (Alpine Linux)** ядро 
>способно удерживать от **2 700 до 6 000 параллельных сессий** (в зависимости от активированного режима защиты)
>за счёт изоляции контекста данных со скоростью поиска `O(1)` и полного отсутствия блокирующих дисковых дисковых операций во время атак.

---

## 🚀 Ключевые особенности (Features)

*   ⚡ **Wire-Speed фильтрация (L5-L7):** Перехват и сброс вредоносных пакетов на этапе `PreLoginEvent` до выделения тяжелой heap-памяти JVM под сессию.
*   🧠 **Анализ энтропии строк:** Динамический разбор гласных/согласных и бесструктурных паттернов генерации никнеймов ботнетов.
*   💾 **Отложенный ввод-вывод (Deferred IO):** Асинхронное пакетное сохранение черных списков на диск раз в 30 секунд для предотвращения дисковых зависаний (I/O Bottlenecks).
*   🔥 **Ядерный контур L3:** Автоматическая генерация аппаратных правил для Netfilter (`ipset` / `iptables`) прямо из оперативной памяти плагина.
*   🛑 **Анти-Абьюз капканы чата:** Система динамического трекинга связанных сессий. Отрезает «умных» рекламных ботов, дублирующих текст с разных аккаунтов, полностью исключая ложные баны честных игроков.

## ⚡ Быстрый старт на Linux (L3 Hardware Mitigation)

Вы можете применить железную защиту ядра Linux Netfilter. Выполни в терминале машины эти команды:

```bash
# 1. Создаем быстрый хэш-сет для ядра
sudo ipset create lodosck_ban hash:ip

# 2. Привязываем сет к правилам фильтрации iptables на DROP
sudo iptables -A INPUT -m set --match-set lodosck_ban src -j DROP

# 3. Настраиваем ежеминутную синхронизацию persistent-файла с RAM ядра (Crontab)
cat plugins/LoDosCk/banlist.txt | xargs -I {} sudo ipset add lodosck_ban {} 2>/dev/null
```
